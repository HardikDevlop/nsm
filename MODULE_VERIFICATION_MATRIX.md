# Current NMS Module Verification Matrix

**Audit date:** 2026-08-29  
**Scope:** Current repository implementation only.  
**Method:** Static inspection of frontend routes/components, API client, FastAPI routes, services/collectors/listeners, SQLAlchemy models, migrations and tests. No application code was changed.

## How To Use This Matrix

Run each procedure in an isolated test environment with PostgreSQL and the backend available. A listed API writer is not treated as a collector or listener unless the repository actually wires it to a collector, receiver or application lifecycle. Real-device tests remain optional and must use approved lab devices; unit tests must not require production devices.

The current local runtime was unavailable during this audit: PostgreSQL `127.0.0.1:5432`, Redis `127.0.0.1:6379`, backend `127.0.0.1:8000` and frontend `127.0.0.1:5173` were not listening. Therefore this document defines verification procedures and code-based expectations, not claims of live success.

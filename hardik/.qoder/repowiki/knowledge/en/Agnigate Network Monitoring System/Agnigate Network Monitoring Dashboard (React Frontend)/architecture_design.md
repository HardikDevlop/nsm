The app follows a thin MVC-like split inside `src/`: `views/MonitoringView.jsx` is the sole React view that composes the entire UI shell (login panel, side navigation, KPI grid, panels) and owns all presentation state. Business logic is delegated to `controllers/monitoringController.js`, which exposes an `initializeMonitoringController()` factory returning `getState` and `refreshState`. Data transformation lives in `models/monitoringModel.js` (`createInitialState`, `mapInventoryToState`). HTTP calls are isolated in `services/inventoryService.js`, which fetches `/api/inventory` — proxied by Vite to `http://127.0.0.1:5000` during development. Reusable presentational components `DeviceList.jsx` and `StatusCard.jsx` live under `components/` and are styled via co-located CSS modules in `styles/`. The entry point `main.jsx` mounts `<App />` into `#root` wrapped in React StrictMode; `App.jsx` renders only `MonitoringView`, keeping the component tree flat.

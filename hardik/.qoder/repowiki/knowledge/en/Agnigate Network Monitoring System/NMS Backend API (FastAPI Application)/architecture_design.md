The application is bootstrapped in `main.py`, which creates the FastAPI instance, registers CORS middleware via settings, includes the central router from `api/routes.py`, and runs a lifespan hook that creates all SQLAlchemy tables and seeds RBAC roles/permissions. Cross-cutting concerns are centralized: `dependencies.py` provides FastAPI `Depends` for Bearer token decoding, user resolution, and the `require_permission` RBAC factory; `config/settings.py` exposes a cached Pydantic `Settings` object loaded from `.env`; `database/session.py` supplies the SQLAlchemy engine and session factory used by every repository. Models are imported at import time so `Base.metadata` auto-registers them for table creation. Business logic is split into `services/` (discovery, monitoring), data access through `repositories/crud.py` against SQLAlchemy models, request/response validation via `schemas/nms.py`, and security primitives in `auth/security.py`. One-shot scripts (`init_db.py`, `seed.py`) share the same settings and session infrastructure to provision and populate the database independently of the running server.

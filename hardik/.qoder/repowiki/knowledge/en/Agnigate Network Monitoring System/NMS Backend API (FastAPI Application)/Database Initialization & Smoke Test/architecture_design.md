Two complementary entry points live at the backend root: `init_db.py` is a CLI bootstrap that first connects directly to PostgreSQL via `psycopg` to create the target database if it does not exist, then imports the application's SQLAlchemy `Base`, `SessionLocal`, and `engine` from `backend.database.session` to call `Base.metadata.create_all()` and invoke `seed_rbac()`. `seed.py` is a pure data-seeding module that populates `Permission`, `Role`, and `User` records by iterating over a declarative list of CRUD modules and action codes. `smoke_test.ps1` is an independent PowerShell script that exercises the running FastAPI server at `http://127.0.0.1:8000/api/v1`, exercising auth, RBAC, organization/site/device CRUD, metrics/alerts flows, dashboard, audit logs, and cleanup. Dependencies are declared in `requirements.txt` and imported lazily inside functions to avoid circular imports between the bootstrap scripts and the application package.

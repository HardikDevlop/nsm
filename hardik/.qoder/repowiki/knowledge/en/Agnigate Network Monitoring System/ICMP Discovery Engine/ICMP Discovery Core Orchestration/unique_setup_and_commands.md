Two run modes exist: `python main.py` executes a one-shot discovery against `NETWORK_TARGET` (default `192.168.100.0/24`) and writes CSV to `output/inventory.csv`; `python app.py` starts a Flask server on `127.0.0.1:5000` exposing REST endpoints. The scheduler loop can be started programmatically via `SchedulerLoop.start(callback)` with a configurable interval from `MONITOR_INTERVAL_SECONDS`. All output files use paths from `config.py` (`data/inventory.json`, `output/inventory.csv`, `data/logs/`).

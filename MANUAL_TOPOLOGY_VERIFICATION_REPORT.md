# Manual Topology Verification Report

## Scope

Manual Topology only. Network Topology.tsx, backend collectors, polling intervals, OIDs, and Network Topology behavior were not modified.

## Manual data flow

Route /manual-topology loads the latest user-owned ManualTopologySnapshot through the Manual Topology API, hydrates local workspace/cache state, and keeps manual nodes/links separate from actualWorkspace. Save/update persists the workspace payload. Reconciliation calls the backend snapshot reconcile endpoint and compares observed links against manual links. View switching changes UI state only.

Manual data is stored in manual_topology_snapshots with change records in manual_topology_changes. UI-only viewport/selection state uses local storage and is separate from persisted topology.

## Discovery audit

The current handler is runPhysicalDiscovery() in figma design/src/pages/ManualTopology.tsx. It first attempts to hydrate topology-layout-cache-v2, which is the final logical layout generated by Network Topology. It then maps cached nodes/links through discoverPhysicalLinks().

Before this change it fell back to getSNMPTopology(undefined, false) when the final cache was unavailable. That was a raw-only/divergent discovery path. The fallback has been removed: Manual Discovery now fails safely if the final Network Topology graph is unavailable, and it does not save or overwrite manual work with a raw graph.

Diagnostic stages currently log MANUAL_DISCOVERY_USING_FINAL_NETWORK_GRAPH, MANUAL_DISCOVERY_FROM_NETWORK_TOPOLOGY, DISCOVERY_LINK_TRACE, and DISCOVERY_LINK_DISCARDED.
